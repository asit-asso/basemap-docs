Data schema

Information about data schema used in a tileset is already available in the metadata tiles.json file (see tileset). Encoded objects are separated into different layers available under the key vector_layers. For each of them, fields name and their description and possible values are available.

We give here more detailed information about tilesets data schema.

Info

Even if a layer is available for a given zoom level, it still may contain no features because we filter out objects that are too small for a given zoom level.
